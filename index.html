📐 Mean — The Fair Share

Mean is the average. Add all values, divide by how many there are. It tells you what each person would get if everything was shared equally.

🍕 Real-Life Idea

5 friends order pizza. One eats 1 slice, another eats 3, another 5, another 3, another 3. Total = 15 slices, 5 people.
Mean = 15 ÷ 5 = 3 slices — if everyone had eaten equally, each would get 3.
Mean (x̄) = Sum of all values / Number of values = Σxᵢ / n

🧮 Step-by-Step Example

Marks of 7 students: 45, 67, 72, 45, 89, 60, 72

The Numbers

Mean value
Data values
Step 1: Add all → 45 + 67 + 72 + 45 + 89 + 60 + 72 = 450
Step 2: Divide by 7 → 450 ÷ 7 = 64.3
Mean = 64.3 marks

✅ When Mean works well

When data has no extreme outliers. Example: exam marks of a class, daily temperature, runs scored in 10 overs.

⚠️ When Mean misleads

A CEO earning ₹50 crore joins a team of 9 people earning ₹50,000 each. Mean salary shoots up — but it doesn't represent anyone's actual pay! Affected by extremes

📍 Median — The Middle Person

Median is the middle value when data is sorted in order. Half the values are below it, half are above it.

🚶 Real-Life Idea

7 people stand in a line sorted by height. The 4th person is the median — 3 people are shorter on one side, 3 are taller on the other. The median person is right in the middle.
Odd n: Median = value at position (n+1)/2
Even n: Median = average of n/2 and (n/2 + 1) positions

✅ Median's superpower

NOT affected by extreme values. Even if one student scores 0 or 100, the middle value doesn't change much. Outlier-proof!

🏠 Real-world use

News always says "median household income" or "median house price" — because a few billionaires would skew the mean. Median gives the true picture of the typical person.

🏆 Mode — The Most Popular

Mode is the value that appears the most number of times. It's the crowd favourite — the most common value in the data.

👟 Real-Life Idea

A shoe shop records sizes sold today: 6, 7, 8, 8, 9, 7, 8, 6, 8, 7, 8
Size 8 appears 5 times — more than any other.
Mode = 8 → Order the most stock in size 8!
Mode = value that occurs most frequently in the data

📊 Visual Example — Spot the Mode

Frequency of each marks value

Mode = 45

📌 Multiple Modes

Data can have no mode (all values unique), one mode (unimodal), or two modes (bimodal). Example: 45, 45, 67, 72, 72 — two modes: 45 and 72.

🎯 When Mode is most useful

When you need the most popular choice — most common T-shirt size to manufacture, most popular subject chosen by students, most frequent age in a population.

📦 Grouped vs Ungrouped Data

The same data can be presented in two different ways. As you deal with larger datasets, grouping becomes essential.

🗂 Ungrouped Data

Raw individual values, listed one by one. Easy when data is small.

Marks of 10 students:
45, 67, 72, 45, 89, 67, 45, 90, 72, 60
✅ Shows every individual value
✅ Exact mean, median, mode possible
❌ Gets unwieldy with 1000+ values

📊 Grouped Data

Values organized into class intervals. Used when data is large.

Marks (Class Interval)Students (fᵢ)
40 – 604
60 – 804
80 – 1002
Total10
✅ Compact, easy to read
✅ Works for thousands of values
⚠️ Individual values lost — use class mark

🔖 Class Mark — The Key Idea in Grouped Data

In grouped data, we don't know the exact values inside each class. So we use the class mark (midpoint) as a representative value for the whole class.

Class 40–60 → Class mark = (40 + 60) ÷ 2 = 50
Class 60–80 → Class mark = (60 + 80) ÷ 2 = 70
Class 80–100 → Class mark = (80 + 100) ÷ 2 = 90
Class Mark (xᵢ) = (Upper Class Limit + Lower Class Limit) / 2

📐 Mean from Grouped Data (Direct Method)

We multiply each class mark by its frequency, sum up, then divide by total frequency:

Class IntervalfᵢClass Mark (xᵢ)fᵢ × xᵢ
40 – 60450200
60 – 80470280
80 – 100290180
Total10—660
x̄ = 660 / 10 = 66

Note: Exact mean from ungrouped data = 65.2. Grouped gives 66 — slightly different because we used class marks as approximations.

📈 Cumulative Frequency

Cumulative frequency is a running total of frequencies. It answers: "How many values are less than or equal to this point?"

🎟 Real-Life Idea — The Queue

30 people are in a queue to enter a stadium. After the gate, a counter clicks for each person who passes.
After 4 people pass → counter shows 4
After 10 more pass → counter shows 14
After 6 more pass → counter shows 20
That running count is exactly cumulative frequency!

📈 The Ogive — Cumulative Frequency Curve

Plot (upper class limit, cf) → join with a smooth curve → you get the Less Than Ogive (S-shaped). The halfway point (n/2 = 15) gives the Median.

On the Y-axis, find n/2 = 15 → draw horizontal line to curve → drop vertical → read X value.

🔗 The Empirical Relationship (NCERT)

For moderately skewed distributions, these three are approximately related:

3 × Median = Mode + 2 × Mean
Using our values: Mean ≈ 65.2, Mode = 45, Median = 67
Check: 3 × 67 = 201   |   45 + 2×65.2 = 175.4 ← Not exact, it's approximately true
Useful tip: If you know any two, you can estimate the third!

🧭 Quick Decision Guide — Which to Use?

💰

Use Mean when data is balanced — average marks, average rainfall, average speed.

🏡

Use Median when a few extreme values could distort the picture — house prices, incomes, ages.

👗

Use Mode when you need the most popular choice — clothing sizes, favourite colour, most common age.
